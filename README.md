## v1.1.0 改动内容

### 修复的问题

- 菜单输入字母或非数字时直接崩溃，改为重新选择。
- 无效选项的重新输入逻辑错位。
- 精英怪等级与血量、攻击对不上（先按旧等级算数值再改等级）。
- 存档写在进程工作目录下，换位置启动就读不到；现在固定写到程序目录的 `saves` 子目录，并兼容旧存档。
- 存档损坏时读档直接崩溃，现在会捕获异常并修正非法数值。
- 战斗中按错键直接结束战斗，现在只提示重选。
- 治疗逻辑在菜单与战斗中重复实现，已统一。
- 没有真实控制台时清屏/读键会崩溃，已统一兜底。
- 标准输入读完后菜单与战斗会陷入死循环，现在会主动退出。

### 数值平衡调整

| 项目 | 原值 | 现值 |
| --- | --- | --- |
| 升级所需经验 | `等级 × 100` | `100 + 等级 × 60` |
| 升级增加最大HP | +20 | +18 |
| 升级回血 | 直接回满 | 恢复 35% 最大HP |
| 治疗量 | 固定 50 | `20 + 等级 × 6` |
| 战斗治疗次数 | 无限制 | 每场最多 3 次 |
| 受击减伤 | `怪物攻击 - 玩家等级` | `怪物攻击 × (1 - 0.05 × 等级)`，最低 35% 减伤 |

详细说明见 `DevelopNotes.md`。
